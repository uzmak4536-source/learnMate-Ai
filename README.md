# LearnMate AI — SDG 4: Quality Education

A simple static website prototype demonstrating an educational learning assistant.

## Features
- Topic-based beginner explanations (photosynthesis, fractions, algorithms)
- Sample quiz with instant feedback
- Responsive layout for desktop and mobile
- SDG 4 relevance and future-improvement ideas

## Run locally
Open `index.html` in a modern web browser. No installation or server is required.

## Important
This is a demonstration prototype. It uses pre-written sample explanations and does not connect to an AI API or save personal data. Do not claim that live AI integration exists.

## Publish for a project preview link
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository and commit the files.
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. Copy the published `https://...github.io/.../` URL into the form's **Project Preview Link** field.
